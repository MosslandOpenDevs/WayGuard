# Stitch Prompt Pack

This folder holds reusable prompts for the current Safety Guardian Stitch project.

## Source of Truth
- Project metadata: `stitch.json`
- Design language: `DESIGN.md`
- Product map and backlog: `SITE.md`
- Current baton for the next Stitch pass: `next-prompt.md`

## Prompt Files
- `home-map-reframe.md`: Home map refresh centered on community activity.
- `landing-home-launch.md`: Public introduction homepage that funnels visitors into the live web app.
- `landing-home-refine.md`: Short follow-up prompt for correcting the landing page tone and Korean copy.
- `report-screen-refresh.md`: Faster and clearer report submission flow.
- `safe-return-refresh.md`: Stronger guardian-focused safe-return dashboard.
- `community-feed-refresh.md`: Cleaner local feed and post composer.
- `child-safety-refresh.md`: Route-confidence framing instead of public infrastructure counts.

## Working Rule
Large UI changes should start in Stitch. After a direction is approved, React should absorb the selected structure and spacing with minimal guesswork.
