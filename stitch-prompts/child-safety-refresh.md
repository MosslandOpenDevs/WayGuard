A mobile child-safety monitoring screen for Safety Guardian.

This screen should help a guardian understand whether a child route feels safe without presenting raw government-infrastructure counts as the main story. Frame the page around route confidence, guardian alerts, and trusted nearby help points.

**DESIGN SYSTEM (REQUIRED):**
- Platform: Mobile web app
- Theme: Reassuring, guardian-focused, clear
- Primary Accent: Safety Blue (#2764e7)
- Positive Accent: Emerald (#10b981)
- Caution Accent: Amber (#f59e0b)
- Surfaces: Rounded cards, soft shadows, bright elevated panels

**Page Structure:**
1. Intro hero with child-safety context.
2. Route check card with start and destination.
3. Analysis result card with route confidence and identified attention points.
4. Nearby trusted help points list.
5. Guardian alert controls and summary.

**Specific Goals:**
- Use Korean copy for all visible labels.
- Replace CCTV-and-bell storytelling with route confidence, trusted hubs, and alerts.
- Make the screen feel supportive rather than alarming.
