A mobile emergency and hazard reporting screen for Safety Guardian.

Design a report flow that helps a user submit a neighborhood safety issue quickly and confidently. This is not a bureaucratic form. It should feel like a fast mobile action flow.

**DESIGN SYSTEM (REQUIRED):**
- Platform: Mobile web app
- Theme: Light, clear, action-oriented, trustworthy
- Primary Accent: Safety Blue (#2764e7)
- Danger Accent: Red (#ef4444)
- Support Surface: Soft Gray (#f6f6f8)
- Surfaces: Rounded cards, clear hierarchy, soft shadows

**Page Structure:**
1. Header with title and short one-line guidance.
2. Category grid with bold icons and short labels.
3. Photo upload block with privacy warning and preview.
4. Location confidence card showing the detected location.
5. Description field with clear placeholder guidance.
6. Sticky bottom submit button.

**Specific Goals:**
- Use Korean copy for all visible labels.
- Make category selection fast and obvious.
- Make privacy warnings feel clear without dominating the page.
- Keep the screen visually lighter than a formal complaint form.
- The main call to action should feel safe and decisive.
