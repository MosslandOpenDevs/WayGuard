A public-facing landing homepage for Safety Guardian that introduces the product to first-time visitors and moves them into the live web app. The page should feel warm, trustworthy, and practical for residents, parents, and local communities. This is a launch page for sharing, not an app-store clone and not a corporate SaaS site.

**DESIGN SYSTEM (REQUIRED):**
- Platform: Responsive marketing homepage with a strong mobile-first bias
- Desktop Behavior: Expand gracefully on desktop while preserving the mobile product feel
- Theme: Light, calm, trustworthy, neighborhood-focused
- Background: Soft white and mist-gray layers with subtle map-line or neighborhood-grid texture
- Primary Accent: Safety Blue (#2764e7)
- Secondary Accent: Emerald (#10b981)
- Warning Accent: Amber (#f59e0b)
- Danger Accent: Red (#ef4444)
- Typography: Inter-like modern sans serif with bold compact headers
- Surfaces: Large-radius cards, bright white panels, soft shadows, occasional frosted overlays
- Interaction Style: Practical, reassuring, launch-ready, not flashy
- Product Framing: Everyday neighborhood safety companion powered by resident activity
- Avoid: Purple neon, enterprise dashboards, fear-heavy emergency branding, CCTV-first storytelling, app-store chrome, bureaucratic copy

**Page Goals:**
- Explain the product in one quick glance.
- Make visitors understand that the product works immediately on the web.
- Push the user toward opening the live app, not downloading from an app store.
- Show that the product combines map awareness, resident reports, community tips, and safe-return support.
- Keep all visible copy in Korean.

**Suggested Copy Direction:**
- Hero headline idea: `우리 동네 안심 정보, 한눈에 보고 바로 공유하세요`
- Hero subcopy idea: `위험 제보부터 귀가 안심 공유까지, 주민이 함께 만드는 생활 안전 서비스`
- Primary CTA: `웹에서 바로 시작`
- Secondary CTA: `기능 둘러보기`
- Trust cards: `주변 제보 확인`, `동네 제보 공유`, `귀가 안심 지원`
- Install section titles: `아이폰에서 시작하기`, `안드로이드에서 시작하기`

**Page Structure:**
1. **Hero Section**
   - Strong Korean headline about checking local safety and acting quickly in one place.
   - One short supporting paragraph.
   - Primary CTA: `웹에서 바로 시작`
   - Secondary CTA: `기능 둘러보기`
   - Include a polished device mockup that previews the actual app home map and score card.

2. **Trust Snapshot**
   - Three compact highlight cards that communicate immediate value.
   - Themes: nearby report visibility, community signals, safe-return confidence.
   - Use short Korean labels and simple number or badge styling.

3. **Core Features**
   - Four feature cards:
     - `지도에서 바로 확인`
     - `위험 상황 빠른 제보`
     - `귀가 안심 공유`
     - `동네 커뮤니티 제보`
   - Each card should feel like a real resident workflow, not a technical feature list.

4. **How It Works**
   - Three-step horizontal or stacked flow:
     - `주변 상황을 확인하고`
     - `직접 제보하거나 공유하고`
     - `귀가하거나 가족과 안심 정보를 나눈다`
   - Keep this section easy to scan.

5. **Use Cases / Audience**
   - Scenario-driven cards for late-night walks, child route checks, and neighborhood incident sharing.
   - These should feel lived-in and human, not dramatic or sensational.

6. **Install / Access Section**
   - Clearly explain that the product is a web app that works immediately by opening a link.
   - Include separate cards for:
     - `아이폰에서는 Safari에서 홈 화면에 추가`
     - `안드로이드에서는 웹으로 바로 사용하거나 설치`
   - Make this section especially clear because there is no app-store-first flow.

7. **Final CTA + Footer**
   - Repeat the main CTA near the bottom.
   - Secondary supporting text about local safety being easier when residents can see and share together.
   - Footer can include lightweight placeholders for `서비스 소개`, `개인정보 처리방침`, `문의하기`.

**Visual Notes:**
- The hero should feel brighter and more shareable than the in-app UI, but still clearly from the same family.
- Use the real app screens as inspiration for the mockup composition.
- Mix floating cards, soft gradients, and crisp iconography.
- Let the landing page feel intentional on both desktop and mobile, not like a stretched mobile screenshot.

**Specific Goals:**
- Make the first screen persuasive enough to share publicly with friends, families, schools, or local groups.
- Emphasize practical daily reassurance over fear or surveillance.
- Ensure the primary CTA visually dominates over any install explanation.
- Use Korean copy for every visible label, button, and heading.
