A mobile safe-return dashboard for Safety Guardian.

This screen is the emotional center of the product. It should help a user start a safe-return session, register guardians, and understand their travel status at a glance. The design should feel reassuring first and urgent only when necessary.

**DESIGN SYSTEM (REQUIRED):**
- Platform: Mobile web app
- Theme: Calm, protective, clear, mobile-first
- Primary Accent: Safety Blue (#2764e7)
- Positive Accent: Emerald (#10b981)
- Emergency Accent: Red (#ef4444)
- Surfaces: Large rounded cards, soft shadow, bright surfaces

**Page Structure:**
1. Hero section with a large central safe-return action.
2. Destination card with saved destination name and address.
3. Guardian contacts section with compact cards.
4. Live status metrics for location share, alert threshold, and current trip state.
5. Emergency action that is visually distinct but not always dominant.
6. Progress or confidence card for the active trip.

**Specific Goals:**
- Use Korean copy for all visible labels.
- Make the primary start and stop action unmistakable.
- Show guardian trust and active travel status more clearly than raw settings.
- Keep the screen feeling humane and protective, not militarized or panic-driven.
