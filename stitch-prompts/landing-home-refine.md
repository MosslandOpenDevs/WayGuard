Revise the current landing page concept for Safety Guardian. Keep the overall landing-page structure, but make it feel clearly like a Korean neighborhood safety web app instead of a generic SaaS security product.

**Required Changes:**
- Use Korean copy for all visible headings, labels, buttons, section titles, and supporting text.
- Replace generic English messaging like `Your Neighborhood, Understood`, `Lens Features`, and `Protect What Matters`.
- Make the page feel resident-powered, practical, calm, and trustworthy.
- Avoid enterprise SaaS tone, surveillance-heavy language, and abstract security branding.

**Must-Show Product Story:**
- `지도에서 바로 확인`
- `위험 상황 빠른 제보`
- `귀가 안심 공유`
- `동네 커뮤니티 제보`

**CTA Requirements:**
- Main CTA must be `웹에서 바로 시작`
- Secondary CTA can be `기능 둘러보기`
- Make it obvious that this product works immediately on the web, not through an app-store-first flow

**Access Section Requirements:**
- Add a clear section explaining:
  - `아이폰에서는 Safari에서 홈 화면에 추가`
  - `안드로이드에서는 웹으로 바로 사용하거나 설치`

**Visual Direction:**
- Match the real app more closely: Safety Blue (#2764e7), rounded white cards, soft shadows, floating panels, map-centered product feel
- Use a polished device mockup that looks like the actual home map screen and safety summary card
- Keep the page clean and shareable on desktop, but preserve a mobile-first feeling
- Remove any placeholder content, awkward generic icons, or filler copy

**Suggested Korean Copy Direction:**
- Hero headline: `우리 동네 안심 정보, 한눈에 보고 바로 공유하세요`
- Hero subcopy: `위험 제보부터 귀가 안심 공유까지, 주민이 함께 만드는 생활 안전 서비스`
- Trust cards: `주변 제보 확인`, `동네 제보 공유`, `귀가 안심 지원`

**Goal:**
- The result should feel like a public introduction page for `안전지킴이`, ready to share with parents, residents, schools, and local communities.
